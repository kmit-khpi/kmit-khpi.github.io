# ШІ-напрям КМІТ — усі посилання

Сторінка: https://kmit-khpi.github.io/

Єдине місце з посиланнями для студентів ШІ-напряму кафедри КМІТ НТУ «ХПІ»: з чого почати, інструменти, сім напрямів, публікація проєктів, приклади, правила.

Щоб оновити — відредагуйте `index.html` (кнопка ✏️ на GitHub) і натисніть **Commit changes**; сторінка оновиться за 1–2 хвилини.
